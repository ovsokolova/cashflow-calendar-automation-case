# Метод замера метрик

Описания метрик носят методологический характер: показывают, как
проверять работоспособность процесса и корректность данных.

## Качество данных и заявок
- **Доля заявок с полными аналитиками:** заявки, прошедшие входной
  контроль с первого раза (статья ДДС, договор/контрагент, проект/
  подразделение, дата, сумма, валюта, приоритет) / все поданные заявки.
  Источник: журнал валидации заявок / таблица контроля.
- **Операции «факт без заявки»:** проведённые в учётной системе выплаты
  или поступления, не имеющие связанной плановой заявки в календаре
  на момент сверки. Источник: выгрузка факта из «1С: Бухгалтерия» /
  «Oracle» + реестр календаря.

## Контроль ликвидности и переносов
- **Зафиксированные переносы с причиной:** доля перенесённых платежей,
  для которых указаны новая плановая дата и причина переноса.
  Источник: журнал изменений платёжного календаря.
- **Покрытие разрывов планом действий:** наличие зафиксированного списка
  кандидатов на перенос/корректировку по матрице приоритетов (`P1–P3`)
  при выявлении отрицательного прогнозного остатка. Источник: протокол/
  реестр разбора кассовых разрывов.

## Сверка «План / Факт»
- **Полнота сверки по чек-листу:** доля закрытых периодов, по которым
  пройдены все пункты `artifacts/reconciliation-checklist.md`.
  Источник: чек-лист сверки за период.
