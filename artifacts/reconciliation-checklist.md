# Чек-лист сверки «План / Факт» по ДДС

Используется перед закрытием периода или регулярным план-фактным отчётом,
чтобы отделять реальные отклонения от ошибок данных.

- [ ] Сверены начальные и конечные остатки с выписками / учётной системой.
- [ ] Проверены операции «факт без заявки» (непроведённые заранее или
      срочные оплаты).
- [ ] Проверены операции «заявка без факта» (переносы, отмены или задержки
      исполнения).
- [ ] Выявлены расхождения по суммам и датам с указанием причины
      (условия договора, частичная оплата, курс, ошибка ввода).
- [ ] Проверено заполнение обязательных аналитик (статья ДДС, контрагент/
      договор, проект/подразделение) по проблемным строкам.
- [ ] Сформирована краткая сводка отклонений для разбора с ответственными.
